# Malda Equipment Register

Empty-data HTML application. No operational crew records, storage credentials or private register backups are included.

Open https://locopilotib-gif.github.io/malda-equipment-app/ or download index.html. Each browser and device has its own local database. Opening this link does not connect to an existing register or synchronize devices. Configure your own authorized backup service or viewer connection inside the app. Keep full JSON recovery backups. Browser storage can be cleared by the browser or user.

Local role checks are workflow controls, not server-enforced security against someone controlling the device. Do not commit records, tokens or backups to this public repository.

The source is editable directly in index.html. Physical device and live backend testing are still required before operational deployment.
